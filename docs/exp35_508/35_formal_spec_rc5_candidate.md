## 1. 研究问题与主张边界

**主研究问题**：在按视频隔离、时间向前预测的设置下，相比仅使用过去 60 秒弹幕平均强度的基线模型，加入弹幕强度变化、历史爆发间隔及视频属性等特征，能否改善对未来 30 秒弹幕爆发的预测区分能力？增量幅度与其不确定性如何？

**不主张**（逐条不可删）：

1. 不主张预测视频成为热榜的概率；不主张因果效应。
2. 不主张实时预警。数据是日频快照，采集时刻已含 `t` 之后的全部弹幕；"观众走到 t"与"快照采集时刻"两个时点无法同时满足"特征可得 + 标签未知"。
3. 不主张标签等于"真实弹幕全集的爆发"；标签是**观测快照内**相对决策点基线的统计爆发。
4. 不主张爆发 = 高光/精彩/推荐依据。
5. 不主张概率可用——除非校准门通过。
6. 不主张已排除刷量弹幕；不主张剩余"未知多 P"视频均为单 P。
7. 不主张跨平台/跨时期可迁移。

## 2. 模型定义

| 名称 | 特征 | 学习器 | 状态 |
|---|---|---|---|
| **M1** | `log1p_lam` | L2-LR，`C=1.0`，`StandardScaler` **只在训练数据上 fit**，`lbfgs`，`max_iter=1000`，无超参搜索 | **【已批准】2026-10-27** |
| **M2** | `log1p_lam`, `slope`, `since`, `censored`, `prog`, `log1p_duration` | 同上（同一学习器、同一 `C`） | 【已批准】 |
| **M3** | M2 + `ent` | 同上 | 【已批准】次要分析 |
| **M0 / M4** | — | — | **不纳入正式比较矩阵**（无经批准定义；实现层调用即 `raise`） |

**已实现的契约证据**【实测】：`FEATURES_M1 == ("log1p_lam",)`；`X_M1.shape[1] == 1`；`clf.n_features_in_ == 1`；`clf.C == 1.0`；`scaler.mean_ == 训练折均值 ≠ 全量均值`；`n_iter_ = [2]`（M2 为 `[8]`）均收敛；源码无 `GridSearchCV/RandomizedSearchCV/optuna`。对应测试：`test_m1_feature_set_is_exact`、`test_m1_matrix_has_exactly_one_column`、`test_m1_cannot_smuggle_extra_columns`、`test_scaler_fit_on_train_only`、`test_hyperparameter_search_absent`。

**命名与旧阶梯的对应**（只作对照，不改执行）：`M1 ≡ L1`（特征层面；rc1 的 L1 未指定学习器，故不宣称实现等价）；`M2 = rc2.1 "M" − ent − rep`；`M3 = rc2.1 "M" − rep`。

**非对称项（设计固有，论文须写明）**：M1 与 M2 共用 `C=1.0`，但列数为 1 vs 6，**有效正则强度不同**；这是"特征集 vs 特征集"的比较，不是"等有效容量"的比较。

## 4. 标签

```
B = 5 s   PRE = 12 桶（60 s）   H = 6 桶（30 s）   step = H
K = ceil(duration / B)
c[k] = |{ i : floor(time_offset_i / B) = k }|,  k = 0..K-1
λ_t = mean(c[t-PRE:t])
thr_t = max(3.0, λ_t + 2.0·sqrt(λ_t))        # 在 t 处算一次，不在未来窗口滚动
y_t = 1[ max(c[t:t+H]) >= thr_t ]            # >= 含等号
合法点：t ∈ {12,18,24,...} 且 t + H <= K（闭区间上界，最后一点必须保留）
```

- 阈值比较固定为 `float64` 的 `int >= float`，不引入 epsilon。
- 决策点步长 = H，窗口不重叠。
- `λ_t = 0` 时阈值退化为 3.0（相对基线的性质，写进局限：**同一视频内 λ 越高，越难被判为爆发**，解释"强度—标签"关系时不得混入行为学解读）。

## 5. 特征与白名单

| 特征 | 定义（只用 `c[0:t]`） |
|---|---|
| `log1p_lam` | `log1p(mean(c[t-12:t]))` |
| `slope` | `log1p(mean(c[t-6:t])) − log1p(mean(c[t-12:t-6]))`（对数差分，无 epsilon） |
| `since` / `censored` | D2 滚动参照：`e_k = 1[c[k] >= max(3, λ_k+2√λ_k)]`，`k ∈ [max(12,t−12), t)`；无事件 → `(12, 1)` |
| `prog` | `t / K` |
| `ent`（仅 M3） | `−Σ p_k log p_k / log(12)`，12 桶归一；全零/单桶 → 0，均匀 → 1 |
| `log1p_duration` | `log1p(duration)` |

- 白名单 = `{M2} ∪ {ent}`；越界列立即 `raise`，不静默丢弃。
- 黑名单含 `n_dm`、`y`、`thr`、`play`、`tname`、全片聚合量、任何 `time_offset >= t` 的统计量。
- 逐点因果断言：改 `c[t:]` 后该点特征向量逐位不变（对 100% 决策点验证）。

## 7. 评估与推断

**主指标**：`mean_v AUC_v`，每支合格视频一票；单类视频排除、**不填 0.5**。
**资格**：每视频 ≥5 有效决策点、≥2 正、≥2 负。
**主效应量**：`ΔAUC = AUC_macro(M2) − AUC_macro(M1)`。
**不确定性**：配对视频级 Bootstrap 95% CI，`B=2000`，`seed=20261026`，重采样单位 `bvid`，两模型同一批被抽中视频；单次重采样可用视频 < `max(2, round(0.5·n_eligible))` 则丢弃并计数。

**必须同时报告**：实际视频数、合格视频数、资格排除数、每视频正负决策点分布、`auc_v` 的 p10/p50/p90、有效重采样次数与丢弃次数、实际 SD。

**判读规则（已批准）**：
- 不设数值成功门槛；不写"通过/未通过"，只写效应量与区间。
- CI 跨 0 **不等于**无差异；点估计为正 **不等于**有效。
- 若 CI 半宽远大于点估计，结论只能写"证据不足以区分"，不得写"无增量"。

## 8. 校准

按 `bvid` 分组 5 折交叉拟合（`seed=20261026`），顺序固定：折外打分 → 用 OOF 分数拟合 Platt（`logit(p) → y`）→ 正式使用时全 D-train 重拟合基础模型并套用该校准器。禁止用训练内分数拟合校准器；D-dev / D-conf 不参与任何 `fit`。指标：斜率、截距、10 分位可靠性曲线、Brier、Brier skill（不用 ECE）。

### 9.1 N3 / N4 设计规格（待批准，不得直接运行）

| 项 | N3 相邻视频特征置换 | N4 历史窗内桶序打乱 |
|---|---|---|
| 操作 | 把 D-train 的合格视频随机两两配对得 `σ`；`X'_{v,t} = X_{σ(v),t'}`，`t'` 取同序号点；`y` 不变 | 对每点取 `c[t-12:t]` 的多重集随机置换得 `c'`，重算 `slope/since/ent`（`λ` 不变）；`y` 不变 |
| 不等长处理 | 按"点序号"对齐；若 `σ(v)` 的点数 < 当前视频，按 `t' = t mod n_{σ(v)}` 回绕；报告回绕比例 | 不涉及长度（固定 12 桶） |
| 破坏的信息 | 视频级特征—标签对齐；保留特征边缘分布 | 窗内时序排列；保留强度水平 |
| 预期行为 | 接近 0.5 | 若增量依赖时序则下降；若只依赖强度则不变 |
| 失效原因 | 配对视频强度剖面相近；回绕导致重复取样 | `λ` 不变 ⇒ 判别力主要来自 `λ` 时不会掉 |
| 操作检查 | 配对后 `mean|Δ特征| ≥ 0.5 × 跨视频 SD` | 打乱后 `λ` 逐点不变（断言） |
| 验收标准 | `M ≤ 0.55`（单侧） | 预注册 `Δ = M(原) − M(打乱) ≥ 0.02` 且配对 CI 不含 0；若 `Δ<0.02`，结论写"增量不依赖窗内时序"，不得改判据 |
| 随机化 | 配对种子 `20261027`；只跑一次 | 每点置换种子 `20261027`；只跑一次 |

> 两项均为**候选**：批准前不得运行、不得据此调整主模型。

### 10.2 设计估计（正态近似，非事实）

| 量 | 值 | 依赖假设 |

| `MDE(80%)` @134 / @150 / @200 | 0.053740 / **0.050793** / 0.043988 | `(z.975+z.80)·SD/√n`，SD 视为已知 |
