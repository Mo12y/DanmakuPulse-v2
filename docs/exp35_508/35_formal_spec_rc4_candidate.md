## 3. 标签【已批准】

### 3.1 参数（写死，不得因结果修改）

```
B = 5 s   PRE = 12 桶（60 s）   H = 6 桶（30 s）   step = H = 6
min_count = 3.0   sigma = 2.0   MIN_DURATION = 120 s
```

### 3.2 定义

```
K      = ceil(duration / B)
c[k]   = |{ i : floor(time_offset_i / B) = k }| ,  k = 0..K-1
λ_t    = mean(c[t-PRE : t])
thr_t  = max(3.0, λ_t + 2.0·sqrt(λ_t))          # 在 t 处算一次，不在未来窗口滚动
y_t    = 1[ max(c[t : t+H]) >= thr_t ]          # >=，含等号
合法点 = t ∈ {PRE, PRE+6, PRE+12, ...} 且 t + H <= K（闭区间上界，最后一点必须保留）
```

- 用 `floor` 分桶，**不用** `np.histogram`（其末桶右闭）。实现内有源码断言 + 单测。
- 浮点比较固定为 `float64` 的 `max(int) >= float(thr)`，不引入 epsilon、不做四舍五入。

### 3.3 与 rc1/rc2 测试表的对应关系【差异】

rc1/rc2 §4.4 的 T1–T10 是按 `H=12` 写的（例如"长度 23 → 无合法点"只在 `H=12` 成立）。`H=6` 下的同构边界为：**K=17 → 0 个合法点；K=18 → 恰 1 个（t=12）**；T5 的"最后一个未来桶"从下标 23 移到下标 17。单测已按 H=6 重写并在文件内注明。

## 4. 特征【已批准 + 待确认】

### 4.1 特征集

| 模型 | 列 | 状态 |
|---|---|---|
| **M2（唯一主模型）** | `log1p_lam`, `slope`, `since`, `censored`, `prog`, `log1p_duration` | `【已批准】`（任务书 §6.2 的 6 个构念） |
| **M3（次要）** | M2 + `ent` | `【已批准】` |
| **M1（对照基线）** | `log1p_lam` | `【待确认】D-02` |
| M0 / M4 | — | `【阻塞】B-02`：协议正文无定义，**只保留接口，调用即 raise** |

**名称映射**（任务书 → 实现）：`lambda → log1p_lam`，`duration → log1p_duration`。理由：rc1 §5.1 / rc2 §5 已批准的变换就是 `log1p`；不引入新构念，只是同一构念的数值变换。

**M1 的依据**：`M1` 这个名字在任何协议正文里都没有出现。本文件取 rc1/rc2 §7.1 的 `L1 = log1p_lam`（"局部强度"基线）+ §7.3 的 `B1 = λ-only`，这是**唯一有文本依据**的"主比较基线"。仍标 `【待确认】`：请研究者确认"`M1 ≡ L1`"。

### 4.2 定义

```
log1p_lam       = log1p(mean(c[t-12:t]))
slope           = log1p(mean(c[t-6:t])) - log1p(mean(c[t-12:t-6]))     # 对数差分，无 epsilon
ent             = -Σ p_k log p_k / log(12)，p_k 在全部 12 桶归一         # 全零→0；单桶→0；均匀→1
since, censored = D2 滚动参照：e_k = 1[c[k] >= max(3, λ_k + 2√λ_k)]，k ∈ [max(12,t-12), t)
                  无事件 → (since=12, censored=1)；有事件 → (t-k, 0)
prog            = t / K
log1p_duration  = log1p(duration)
```

- 首个决策点 `t=12` 必然 `since=12, censored=1`（无可观察的更早事件）。
- `ent` 用 12 桶归一：`[1,1,0×10] → 0.2790`（单测固定）。
- 所有特征只读 `c[0:t]`：`test_all_features_causal_on_every_point` 对 100% 决策点逐点验证（不是抽样）。

### 4.3 白名单 / 黑名单【已批准】

- 白名单 = `{M2} ∪ {ent}`；任何不在白名单的列**立即 raise**，不静默丢弃。
- 黑名单（含 `n_dm`、`y`、`thr`、`play`、`tname`、全片聚合量、任何 `time_offset >= t` 的统计量）有单测：把 `n_dm` 注入特征列必须失败。

## 6. 评估【已批准】

### 6.1 主指标

```
对每个合格视频 v：auc_v = ROC-AUC(y_t, p_t | bvid=v)
主指标 = mean_v auc_v            # 每视频一票，macro
```

- 合格判据（**先过滤再算**）：每视频 ≥5 个有效决策点、≥2 正、≥2 负、单类视频排除。
- **单类视频排除且不填补 0.5**（单测：三视频含 1 支全 0 → `n_eligible=2`、`eligibility_share=2/3`）。
- 报告 `n_eligible / n_videos`、`auc_v` 的 p10/p50/p90。
- 同一视频内 `duration` 恒定 ⇒ "仅时长"模型视频内 AUC **恰为 0.5**（单测断言到 1e-12；真实数据实测 0.5）`【实测】`。

### 6.2 配对 Bootstrap

- `ΔAUC = AUC_macro(M2) − AUC_macro(M1)`，重采样单位 = **bvid**（整簇），两个模型用**同一批**被抽中的视频。
- `B=2000`，`seed=20261026`，百分位法 95% CI。
- 一次重采样若可用视频 < `max(2, round(0.5·n_eligible))` 则丢弃并计数（防止退化重采样）。
- 记录 `B / seed / unit / n_valid_reps / n_discarded`。

### 6.3 负对照（诊断，不裁决）

| 对照 | 操作定义 | 判据 | D-train 实测 |
|---|---|---|---|
| 标签置乱（评估侧） | 真标签拟合 → 对**视频内置换**后的标签评估，`seed=7` | \|AUC−0.5\| ≤ 0.06 | **0.5105 ✅** |
| 标签置乱（拟合侧） | 置换标签拟合 → 对真标签评估 | \|AUC−0.5\| ≤ 0.06 | **0.3954 ❌** |
| 仅时长 | 特征只有 `log1p_duration` | 视频内 AUC = 0.5000 | **0.500000 ✅** |
| 时间窗前移 | 特征窗口整体前移 6 桶（30 s），标签不变 | 比基线下降 ≥ 0.02 | **0.6177 vs 基线 0.6158 ❌（不降）** |

## 7. 校准【已批准 + 待确认 D-03】

### 7.1 唯一实现方式：按 bvid 分组的 5 折交叉拟合

严格顺序（不得调换）：

1. 取 D-train 全部决策点，按 `bvid` 分组，`seed=20261026` 打乱视频后取模分 5 折 → **同一视频的全部点在同一折**；
2. 对第 f 折：用其余 4 折的**点**拟合 `StandardScaler` + `LogisticRegression(L2, C=1.0)`；
3. 用该模型对第 f 折的点打分 → 得到**折外（OOF）分数**。此时"基础模型从未见过该视频"；
4. 用**全部 D-train 的 OOF 分数 + 标签**拟合 Platt（1 维 logistic，`logit(p) → y`）；
5. 正式使用时：全 D-train 重拟合基础模型 + 套用第 4 步的 Platt 参数。

**禁止**：把同一基础模型对训练视频产生的训练内分数当独立校准预测；用 D-dev / D-conf 拟合任何部分；看到 D-dev/D-conf 指标后再改 80/20。

### 7.2 已实现且被测试的不变量

- 每折 `train ∩ test` 的**视频交集 = 0**（`video_overlap == 0`，单测逐折断言）；
- OOF 覆盖全部点且落在 (0,1)；
- 训练内 macro AUC ≥ 折外 macro AUC（±0.02 容差）；
- 训练入口 `assert_train_only()` 拒绝 `split != "train"` 的行；
- D-conf 路径（`dt=20261027`、`dconf/`、`danmaku-v2/data`）一律 `DataIsolationError`。

### 7.3 校准指标与概率门（沿用 rc2.1 §9.3–9.4）

校准斜率 / 截距 / 10 分位可靠性曲线 / Brier / Brier skill；概率门 = 斜率 95% CI 覆盖 1 且点估计 ∈[0.8,1.25]、截距 CI 覆盖 0、Brier skill > 0。**不使用 ECE。**

- **(c) 扩大 D-conf**：把合格视频门槛提到 ≥900（现实性需研究者判断采集成本）。

| 150 | 97 / **106** / 115 | 1,287 / 1,602 | 2,065 / 2,700 | 0.140 |
| 200 | 131 / 142 / 153 | 1,788 / 2,158 | 2,879 / 3,622 | 0.140 |
| **250** | **165** / 177 / 189 | 2,288 / 2,690 | 3,691 / 4,523 | 0.140 |
| 300 | 200 / 213 / 226 | 2,770 / 3,227 | 4,534 / 5,448 | 0.143 |
| 500 | 338 / 355 / 371 | 4,782 / 5,393 | 7,883 / 9,149 | 0.142 |

**关键发现**：抽 150 支视频只能得到约 **106** 支合格视频。要让"合格 ≥150"在 5% 分位上仍成立，需抽 **250** 支（p05=165）。⇒ **D-conf 实际需采集/入仓 ≥250 支单 P 视频，才能满足"合格 ≥150"。**

### 9.3 建议的 D-conf 正负事件最低数【待确认 D-04】

| 门槛 | 建议值 | 依据 |
|---|---:|---|
| 合格（可评估）视频 | **≥150** | 已批准 |
| 正例窗口总数 | **≥2,288** | n=250 抽样的 5% 分位（1,602 是 n=150 的 p50，不是保守值） |
| 负例窗口总数 | **≥3,691** | 同上 |
| 抽到/入仓视频数 | **≥250** | p05 合格 165 ≥ 150 |

> 计数门槛只保证"AUC 可算"，**不保证 CI 半宽 ≤ 0.02**——后者由视频数与 SD 决定（见 §8）。这组数值是**候选**，不是已批准门槛。
