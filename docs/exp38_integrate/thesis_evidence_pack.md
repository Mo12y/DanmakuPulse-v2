## 1. D1 · 未来 24h 弹幕量预测（余量预测）

- **任务定义**：在视频发布后 6h 的决策时点，用此前已可观测的弹幕到达计数，预测 (6h, 30h] 窗口（"未来 24 小时"）的弹幕总量。样本单元 = (视频, 批次快照)，要求快照时龄 ≥31h（标签窗完整可观测）。
- **数据**：日频采集 20261012–1026 共 14 批，2,417,130 行弹幕、1,588 支视频（剔除已知多 P、status≠ok）。训练窗（first_seen ≤1019 批）918 单元 / 测试窗（first_seen ≥1021 批）395 单元（354 支视频），**bvid 交集 = 0**【实测】。
- **特征（6 列，全部只用 ≤6h 信息）**：log1p(前6h总量)、log1p((3,6]h计数)、log1p((1,3]h计数)、log1p([0,1)h计数)、log1p差分（(3,6]−(1,3]）、log1p(时长)。
- **基线与模型**：B1 = OLS(单特征 log1p 前6h总量)；M = OLS-6列；对照 = HistGradientBoostingRegressor(depth=3)。
- **审计确认结果（时间切测试集，log1p R²）**【实测】：
  - B1 = **0.4532**（与 exp37 逐位一致）；M = 0.5607；HGB = 0.5391。
  - 主判据（exp37 预注册：ΔR²(HGB−B1) ≥0.05 且 95%CI>0，视频级聚类 bootstrap B=2000）：**+0.095 [0.045, 0.144] → POSITIVE**【口径+实测复算一致】。
  - 消融：+最近3h计数(3–6h) 一项即 **+0.069 [0.029, 0.108]**；+时长 → +0.108 [0.071, 0.148]；差分项在对数空间冗余（与计数列线性重合，4列=5列）。
- **模型选择理由（论文可直接用）**：线性模型 (0.561) ≥ 非线性 HGB (0.539)，且系数可解释、零额外依赖——"简单模型已提取全部可用信号，复杂模型无增益"，选择 OLS。
- **命名更正（审计发现）**：exp37 报告所称 "OLS-6" 实为 **5 特征列**（无 c0 列）；exp38 生产版为 6 列（含 c0）。两者 R² 差 <0.002，非计算错误；论文统一用"OLS-6 列"口径并引用 exp38 数字。

## 2. D2 · 节奏结论稳定度预测

- **任务定义**：在 t ∈ {1,3,6,12,24}h 决策时点，预测"当前时点算得的三维节奏结论（cold_pct、cv、主峰占比）到采集结束时是否漂移 ≤0.25×IQR"。这是**对分析结论可靠性的预测**，不是高光/热度预测。
- **尺度冻结**：s_d（IQR）仅由训练期计算（cold_pct 19.80 / cv 0.489 / main_peak_pct 53.22），测试期未参与【实测：audit_results.json D2_recheck.s_d_frozen】。
- **特征（5 列，全部只用 ≤t 信息）**：log1p(前缀弹幕数 k)、t、前缀覆盖度（20 桶）、最近 1h 占比、log1p(时长)。**不含任何三维指标值本身**——标签由 prefix/full 两套指标差构成，模型无法"背规则"，只能从采集动态预测【实测：特征清单核对】。
- **审计确认结果**【实测，与 exp37 逐位一致】：基线 log1p(k) AUC = **0.7914**；HGB = **0.8696**；**ΔAUC = +0.078 [0.060, 0.096]**（视频级聚类 bootstrap）。GroupKFold(5, bvid) OOF AUC = 0.868，与时间切一致。
- **补齐指标（25.5% 正类率下避免单一 AUC）**：PR-AUC 基线 0.526 → HGB **0.725**；precision@前30% 基线 0.502 → HGB **0.609**；Brier 基率 L0=0.255 → HGB **0.120**【实测】。
- **复现声明**：在全新视频群体（日批 1,588 支）上复现了 10-26 探索值（ΔAUC +0.067~+0.116）——时间外部验证成立。

## 3. D3 · 视频内 30s 计数回归（负结果，关闭）

- 与 exp35 分类负结果**任务不同**（幅度回归 vs 二分类爆发）、**结论同向**：视频内 (t,t+30s] 计数幅度，6λ 零参基线与 6 特征 OLS 的视频内 log1p R² 分别为 −0.62 / −0.80（Δ=−0.177 [−0.719,+0.141]；λ>0 子集同向）——**连基线都无法在视频内预测幅度**。

## 4. D4 · 爆发风险概率校准（证据等级与边界）

- **证据等级 1（训练内 OOF，D-train 0902/0907）**【口径：exp37】：LR6+Platt 嵌套 OOF：Brier skill +0.391，校准斜率 0.821 ∈[0.8,1.25]，十分位最大偏差 0.081。零参 −λ 基线：skill +0.375 但斜率 −3.28（只可排序、不可概率化）。
- **证据等级 2（时间外推独立验证，本轮新增）**【实测】：cohort = 日批 1012–1026 中与 D-train 无 bvid 交集的 **51,589 点 / 1,424 视频**（9 月模型 → 10 月数据）；cohort 构建器对 D-train 回放 **lam/y/y_count 100% 一致**（validate_cohort_builder.py）。结果：**Brier skill +0.378，校准斜率 0.93，截距 −0.126**——概率头通过独立验证。
- **跨 cohort 排序不稳定性（必须如实写）**：−λ 排序从 D-train 0.703 → cohort **0.454**（反转）；LR6 从 0.616 → 0.600。⇒ 排序结论依赖 cohort，概率校准是当前唯一跨期稳定的可交付能力。
- **边界**：cohort 验证 ≠ exp35 D-conf 确证（后者需单独授权）；论文若主张"独立验证"引用本 cohort 口径并注明非 exp35 协议产物。

## 6. 限制（论文"局限"节素材）

1. **采集机制**：弹幕池为固定容量带时间空洞的样本；日批 off>duration 行占 1.6e-5（39/2,417,130，未清洗，与历史口径一致）。
2. **样本偏差**：全部视频来自热榜/日批 Top200（热度存活者），结论不外推到全量视频。
3. **时间外推**：D1/D2 测试窗仅 10/21–26 六批；D4 cohort 为 9 月→10 月单次外推；无跨月滚动复验。
4. **标签口径**：D2 的"漂移"以 0.25 IQR 预注册阈值为准，是操作性定义，不等于"结论错误"；D1 目标是池内可观测弹幕量，不是全量弹幕。
5. **单次运行**：全部结果单 seed（20261027）、单次运行；D1/D2 数字有 exp37→exp38 双次独立复算支撑，D4 cohort 为首次运行。

## 7. 序列结构与状态转移（exp47 / exp48.1，2026-10-27）

> **本节是论文写「序列依赖」时唯一允许的口径来源。** exp48 原报告的核心正向结论已被 exp48.1 推翻，
> 见 `experiments/exp48_markov_increment/SUPERSEDED.md`；任何场合不得引用 0.87 nats、98.6% 正向占比
> 或「高弹幕组增量最大」。

### 7.1 三层结论（论文只能按这三层分开写，不许合并成一句）

| 层 | 问题 | 证据（K=4，276 训练 / 70 测试，346 序列） | 结论 |
|---|---|---|---|
| L1 存在性 | 分钟强度序列的顺序可交换吗 | 组内整段置换检验：Θ=−1.0161，零分布 −1.1558 [−1.176, −1.146]，p=0.0005，效应 11.6 SD；K=3/5 同样 p=0.0005 | **不可交换，顺序依赖存在** |
| L2 一阶模型的价值 | 一阶转移矩阵是否优于「该视频自身活动构成」 | M1−B2b = +0.010 [−0.021, +0.042]；K=3 为 −0.032、K=5 为 +0.043（符号随 K 翻转）；对离线视频边际 M1−B2 = −0.078 [−0.111, −0.043] | **无稳健增量** |
| L3 记忆长度 | 二阶比一阶多给多少 | M2−M1 = +0.064 [0.049, 0.080]，85.7% 视频方向为正；K=3 +0.061、K=5 +0.055 | **小幅但稳健** |

### 7.2 可引用数字

| 量 | 值 | 说明 |
|---|---|---|
| 数据 | 日批 20261012–1026，`got≥600 & dur≥300s & 桶数≥15` → 346 支序列 | 分钟桶=60s，第 k 桶状态由该桶弹幕量分位离散化 |
| 状态定义 | K=4，阈值 20/45/92 条每分 | 阈值=训练 276 支桶计数的 P25/P50/P75，单调化+下界 0.5；测试集不参与 |
| 评分 | 逐桶平均 log 概率（nats），Block A `t=1..n−1` 2,565 个目标位置；Block B `t=2..n−1` 2,495 个 | 差值一律同视频同位置配对，视频级 bootstrap B=2000 |
| M1 − B1 | +0.366 [0.308, 0.424]，91.4% 视频为正 | B1=训练集全局边缘（i.i.d.） |
| B2 − B1 | +0.444 [0.383, 0.505] | **视频自身构成本身的价值，比 M1 的总增量还大** |
| M1 − B2b | +0.010 [−0.021, +0.042]，45.7% 为正 | B2b=该视频已发生桶的频率（因果、零训练） |
| M2 − M1 | +0.064 [0.049, 0.080] | 唯一稳健的序列增量 |
| 置换描述性对照 | M1 中位 −1.027 → 置乱后 −1.187 | 逐视频 20 次置换，77.1% 视频方向为正 |

**引用 M1−B1 时必须同时给出 B2−B1。** 只看 +0.366 会把它误读成「顺序信息」；实际上不看任何顺序、
只用该视频自己的状态构成就能拿到 +0.444。两者之差才是顺序结构的净贡献，而这个净贡献
（M1−B2b）与 0 不可区分。

### 7.3 禁止表述（逐条对应被撤回的内容）

| 禁止写 | 为什么 |
|---|---|
| 「状态转移模型相对活跃度基线提升 0.87 nats/桶」 | 该数值是 B2 广播 bug 的产物，修正后为 −0.078 |
| 「98.6% 的视频上转移模型更优」 | 修正后为 22.9%（K=4） |
| 「对 K∈{3,4,5} 完全稳健」 | 稳健的是**负号**（M1−B2），M1−B2b 的符号随 K 翻转 |
| 「高弹幕组的纯转移增量最大」 | 修正后该组为 −0.086，8 个分层无一为正 |
| 「转移结构可跨视频泛化并带来增量」 | 未能击败零训练的视频前缀基线 |
| 「状态 = 互动阶段 / 语义阶段」 | 状态是分钟弹幕量的分位离散化，属操作性强度等级 |
| 「系统实现了高潮/高光识别」 | 候选事件=局部中位基线+2σ，端点滞后 25–60s，人工标注仅 5–6 支 / 33 峰 |

### 7.4 可以怎么写（建议句式）

> 分钟级弹幕强度序列存在可检出的顺序依赖：将各测试视频的桶序整段置乱后，训练所得一阶转移矩阵的
> 每桶对数似然由 −1.016 降至 −1.156（p≈0.0005，效应 11.6 个标准差）。但该依赖并不构成相对
> 「视频自身活跃度构成」的额外预测能力——后者无需任何序列假设即可取得 +0.444 nats/桶的相对增益，
> 显著大于一阶转移相对全局边缘的 +0.366；一阶转移相对因果前缀基线的差值为 +0.010（95%CI
> [−0.021, 0.042]），与零不可区分。仅二阶模型相对一阶稳定多出 0.055–0.064 nats/桶。据此，
> 本文将转移结构定位为**可观察的描述量**，而非可供宣称的预测增益来源。

### 7.5 与 exp47 的关系

exp47 报告的「M1 优于 i.i.d. +0.366 [0.308, 0.426]」在实现上无误（逐点循环，无广播），**结论仍然成立**；
问题在于它容易被读成「转移模型有效」。论文若引用，必须按 §7.2 的配对方式同时给出 B2−B1 与 M1−B2b。
