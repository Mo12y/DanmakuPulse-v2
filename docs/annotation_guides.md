## A. 30 视频高能片段标注（供 B3.3 算法对比实验）

**目标**：为节奏事件检测提供人工真值（时间区间），支撑四法+融合的 Top-K/IoU 评估。

**样本**：`data-out/annotation/highlight_sample.csv`（30 视频；分区分散分层抽样，见生成脚本头注）
**曲线辅助**：`data-out/annotation/curve_<bvid>.csv`（既有 101 点密度曲线，仅辅助——以实际观看为准）

**流程**：
1. 打开 `video_url` 完整观看一遍（正常速度，勿跳）；
2. 记录每一个"高能片段"：情绪爆发/弹幕集中的时点（名场面、笑点、爆点、高潮段）；
3. 对照曲线核对密度峰；不一致时**以真实观感为准**并在 note 注明；
4. 填入 `highlight_annotation.csv`：`bvid, seg_id, start_s, end_s, note`（note ≤10 字，如"名场面/爆笑/泪点"）。

**口径**：
- 时间粒度：秒；边界取"明显开始的点"（后续评估用 IoU，宽松边界可接受）；
- 每视频标 **3–10 段**；间隔 <5s 的相邻片段合并为一段；
- 连续无感的视频（如纯资讯）可标 0–2 段（如实反映）。

**质检**：标注前先看 2 个示范视频统一标准；抽查 3 个视频复核边界一致性（IoU>0.5 视为标准一致）。

## B. 情感三态标注 800–1000 条（供 B5.2 验证闭环）

**目标**：双人独立标注 → Cohen's κ（门槛 ≥0.6）→ 三态 macro-F1/混淆矩阵——**这是词典验证闭环的唯一合法来源**。

**样本**：`sent_sample.csv`（1000 条；分区配额抽样；**不含任何机器预测**——防锚定偏差）。
两位标注者**各自独立**填写 `sent_ann_A.csv` / `sent_ann_B.csv`（**互不可见对方进度与结果**）。

**流程**：
1. 每条读 `text`（可参考对应视频标题），四选一：`pos / neg / neu / obj`；
2. 不确定时选最接近项并在 `unsure` 列标 1；
3. 全部完成后交回，由第三方脚本算 κ 与一致率；
4. **κ≥0.6 → 通过**；否则词典迭代一轮（扩充+人工过滤）后重标（11 §5 决策点）。

**口径细则（v0，先定死）**：
- 喜悦类（哈哈哈/笑死/好耶）→ `pos`；感动/共鸣类（泪目/破防/绷不住）→ `pos`（B 站语境惯例）；
- 反讽/阴阳怪气：按**字面极性**标（"太强了"标 pos），不单独处理（v0 局限，记入报告）；
- 纯陈述（"第3集""前方高能"）→ `obj`；
- 缩写/梗无法判断 → `neu` + `unsure=1`；
- 同时含正负（"又美又虐"）→ 按**主要倾向**，拿不准标 `neu`+unsure。

⚠️ **纪律**：B 任务的 κ 与 macro-F1 在两位标注者完成前**不得填入任何报告**；`m5_report.json` 的
`sample_queue` 与机器打分仅作**对照物**，不构成验证结论。
