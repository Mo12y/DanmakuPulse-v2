口径边界（逐条对应实现）：
① 状态 = 按分钟弹幕量做分位离散化得到的强度等级（K=4，阈值 20/45/92 条每分，仅由训练 276 支视频估计）， 是操作性类别，不是人工确认的语义阶段，也不是"高潮/低谷"判定。
② 转移矩阵来自训练集全局估计，不使用本视频重新拟合；页内"本视频转移次数"仅作描述。 exp48.1 已核实：该转移结构相对"本视频自身状态构成"基线无稳健增量（M1−B2b=+0.010 nats/桶，95%CI 含 0）， 因此转移只作为可观察的描述量呈现，不宣称它优于活跃度基线。
③ 候选事件 = 局部中位基线 + 2σ 的算法候选，未经人工确认，端点存在 25–60s 系统滞后；不得读作"已验证高光"。
④ D1 = 发布后 6h 时点对 (6h,30h] 弹幕量的预测（OLS-5f，时间切 ΔR²=+0.095 [0.045,0.144]）； D2.p_stable = 当前节奏结论到采集结束不漂移（≤0.25 IQR）的模型概率（HGB，时间切 ΔAUC=+0.078 [0.060,0.096]）； D2.stable_measured 是实测值，与模型概率严格区分。二者是辅助预测，不等于互动节奏识别。
⑤ 训练数据窗 20261012–1026，多 P 已知视频剔除；pending = 标签窗口尚未完全观测。
⑥ 离线评估的切分：D1/D2 均按首批日期做时间切——训练用 首批 ≤ 20261020、测试用 首批 ≥ 20261021， 两侧 bvid 不相交（防同视频跨集泄漏）。D1 可评分样本 1,313 个视频-批次（视频时龄 ≥ 31h 才闭合标签窗口）； D2 训练样本 8,326 个 (视频, t) 点。指标 ΔR² / ΔAUC 均在该时间切上计算， 不是随机切分结果，也不代表跨月滚动复验（未做）。
